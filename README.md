# Ledgerly — Complete Bookkeeping & Accounting Website

Ledgerly is a full accounting website build that combines top feature patterns from:

- QuickBooks
- Xero
- FreshBooks
- Wave
- Zoho Books

It includes both:

1. **Public marketing/product pages**
2. **Interactive accounting suite modules**

## Implemented modules

- Dashboard KPIs (revenue, expenses, receivables, estimated tax)
- Invoice control center (create, send, mark paid, recurring option)
- Expense workspace (categorized entries + billable tagging)
- Bank feed and reconciliation workflow
- Reporting and margin trend visualization
- Tax/compliance checklist center
- Client portal preview
- Automation rules toggle studio
- Architecture benchmark matrix
- Pricing page

## Tech stack

- React
- TypeScript
- Vite
- React Router
- LocalStorage persistence for app data

## Run locally

```bash
npm install
npm run dev
```

## Build

